# Documentation Writer

Write or update the requested Hiko documentation. Follow the shared repository
instructions in [AGENTS.md](../../AGENTS.md), the
[development standard](../project/dev-standard.md), and
[documentation guidance](../project/how-to-document-hiko.md).

- Read the relevant topic index, maintained docs, and implementation before
  stating how a feature behaves.
- Distinguish implemented behavior, design intent, proposals, and historical
  context. Keep the whitepaper focused on rationale and topic docs on contracts.
- Place new docs in the nearest topic folder and update its index. Link to
  existing sources rather than copying explanations into multiple files.
- Keep examples valid and commands consistent with the current repository.
- Edit source documentation rather than generated output unless regeneration is
  part of the task. Check local links and references after editing.
- Report the changed docs, factual gaps found, and validation performed.
